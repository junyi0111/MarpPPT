# Code of Conduct / 社群行為守則

MarpPPT welcomes people who want to use, improve, or discuss the project. This policy applies to project-managed issues, pull requests, reviews, and discussions. Maintainers and contributors are held to the same standard.

MarpPPT 歡迎所有使用、改進或討論本專案的人。本守則適用於專案管理的 Issue、Pull Request、程式碼審查與討論；維護者和貢獻者遵守相同標準。

## Expected behavior / 期待的行為

- Be respectful. Discuss ideas and code without attacking the person proposing them.
- Give specific, constructive feedback and make room for different experience levels and viewpoints.
- Keep reports relevant and protect other people's private information, documents, and presentation files.

- 尊重他人，討論想法與程式碼時不做人身攻擊。
- 提供具體、可行的回饋，尊重不同經驗程度與觀點。
- 保持討論與專案相關，保護他人的個人資訊、文件與簡報檔案。

## Unacceptable behavior / 不接受的行為

Harassment, threats, discriminatory language, sexualized attention, personal attacks, deliberate disruption, spam, and publishing someone else's private information without permission are not allowed.

不得騷擾、威脅、歧視、性騷擾、人身攻擊、蓄意干擾討論、張貼垃圾訊息，或未經同意公開他人的私人資訊。

## Reporting and response / 回報與處理

For content in an issue, pull request, or comment, use GitHub's **Report content** option. Choose **Report to repository admins** when GitHub offers it; otherwise, or for serious abuse, use **Report abuse to GitHub Support**. Do not post sensitive details or personal information in a public issue. See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Report security vulnerabilities through [SECURITY.md](SECURITY.md), not through a public issue.

若問題出現在 Issue、Pull Request 或留言，請使用 GitHub 的 **Report content**。若介面提供 **Report to repository admins**，可向維護者回報；否則或遇到嚴重濫用情況，請使用 **Report abuse to GitHub Support**。不要在公開 Issue 張貼敏感細節或個資。操作方式見 [GitHub 回報說明](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)。安全漏洞請依 [SECURITY.md](SECURITY.md) 回報，不要公開張貼。

Maintainers will review project-space conduct concerns case by case. Depending on the situation, they may remove content, ask for changes, close or lock a conversation, or restrict participation. They will avoid repeating private details in public responses.

維護者會依個案處理專案空間中的行為問題，可能移除內容、要求修正、關閉或鎖定討論，或限制參與；公開回覆時會避免重述私人細節。
